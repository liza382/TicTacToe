# TicTacToe
Руководство пользователя


Программа "Крестики-нолики" предназначена для игры двух игроков.
Игроки по очереди ставят крестики (Х) и нолики(О) на поле 3х3.
Побеждает тот, кто первым соберет три одинаковых символа по горизотали, вертикали или диагонали.
Если все клетки заполнены, а победителя нет, объявляется ничья. 
Для начала новой игры нажмите кнопку "начать заново"
